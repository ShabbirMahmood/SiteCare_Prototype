SITECARE PROTOTYPE

Local Python web application for a 14-site photograph workspace and visit planning.
GitHub: https://github.com/ShabbirMahmood/SiteCare_Prototype

Documentation in this folder:
  README.md                    Short overview, architecture map and workflow diagram
  user_manual.md               English and Japanese user manual
  setup_instruction.md         VS Code/CMD setup, accounts, stopping and port recovery
  technical_architecture.md    Detailed implementation, database, APIs and backups
  docs/TEST_REPORT.md           Recorded verification results

Start: activate .venv, then run python.exe run.py.
Open http://127.0.0.1:8000/ and keep the server terminal open.
Stop: press Ctrl+C in the server terminal.

Use synthetic/de-identified data for prototype evaluation. Not clinically validated.
